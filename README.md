# 合成大奶蛙 · 梗合成

一个合成大西瓜玩法的**网络热梗**小游戏。零依赖、零构建：**双击 `index.html` 就能玩**。

## 这个玩法是怎么来的（B站调研）

在 B 站搜「奶龙 小游戏 / 网络热梗 小游戏」，当前最能打的梗小游戏形态是**「合成大奶蛙」**——合成大西瓜的物理合成玩法套上奶家人梗角色，一堆实录视频在卷分数：

- [合成大奶蛙 7697 分实录](https://www.bilibili.com/video/BV1ZGYP64Eys)（标题里直接写了规则："两个奶蛙合成大奶蛙"）
- [合成大奶蛙 14125 分实录](https://www.bilibili.com/video/BV1siHn6REBo)
- [合成大奶蛙暴力清屏](https://www.bilibili.com/video/BV1T2Yc6iEkt)
- [奶蛙是从哪里来的？](https://www.bilibili.com/video/BV1FwoFB3EJ7) / [梗百科：奶龙大笑是啥梗？变异奶龙？！](https://www.bilibili.com/video/BV1ZPieB5EK7) —— 角色谱系来源

所以这个项目的规则不是拍的，是从视频标题里还原出来的：**两个相同梗相撞合成升级**，而
**「两个飞天奶龙合成湮灭」**是这套玩法里的最高成就，对应视频里的**「暴力清屏」**。

## 梗阶梯（10 级）

合成是环环相扣的：两个奶墩 → 一个奶娃，以此类推。

| # | 梗 | 出处 / 梗点 | 半径 | 合成得分 |
| --- | --- | --- | --- | --- |
| 1 | 奶墩 | 奶家最小只 | 22 | — |
| 2 | 奶娃 | 「奶娃之母」 | 26 | +2 |
| 3 | 奶龙 | 「奶龙宇宙无敌超长合集」 | 31 | +5 |
| 4 | 奶蛙 | 「奶蛙卖油条，规矩不能破」 | 37 | +10 |
| 5 | 奶蛙大笑 | 「看完不笑可以确诊奶浓症」 | 43 | +18 |
| 6 | 变异奶龙 | 「奶龙大笑是啥梗？变异奶龙？！」 | 50 | +30 |
| 7 | 卡皮巴拉 | 情绪稳定 | 58 | +50 |
| 8 | 哈基米 | 哈基米哈基米 | 66 | +80 |
| 9 | 飞天奶龙 | 起飞 | 75 | +130 |
| 10 | 湮灭 | 暴力清屏 | 86 | +300 |

**两个飞天奶龙 → 湮灭**：会先蓄力、然后炸开一圈冲击波，把半径 380 以内的梗全部清掉（每个还额外算分），
最后自己坍缩消失。这是全局最高分的来源，也是唯一的「暴力清屏」手段。

## 玩法与操作

- 移动鼠标 / 手指选位置（也可以 `←` `→` 微调），**点击 / 空格**投放。
- 两个相同的梗一碰到就合成升级，分数按上表结算。
- **连锁合成**：0.9 秒内连续合成算连击，倍率 ×1.5、×2、×2.5……（上限 ×4）。
- **轻点一下**（不蓄力）不会改变位置，可以先把大梗放到想要的位置。
- 堆到**红线以上**并静止超过 1.5 秒 → 本局结束。越接近红线，红线越红、会亮起「危险！」。

| 操作 | 键位 |
| --- | --- |
| 左右移动 | 鼠标 / 触摸拖动 / `←` `→` |
| 投放 | 点击、`空格` |
| 交换当前与下一个 | `S`，或点右上角「下一个」卡片 |
| 重开 | `R` / `Enter` |
| 音效开关 | `M` 或右上角喇叭 |

「梗图鉴」记录你合成过的每一个梗（存在 `localStorage` 的 `hdnw.bits`），最高分存在 `hdnw.best`。
音效（投放、合成音阶、飞天奶龙起飞、湮灭爆炸、结束）全部由 WebAudio 现场合成，没有任何音频文件；
10 个梗也全是 canvas 矢量画的，没有一个图片资源。

## 实现要点

- **物理**：固定步长 1/120 累积器 + 圆-圆冲量求解（质量按 r² 加权、位置修正带 slop、
  切向摩擦 0.26），每步两遍贴墙钳制——第二遍专门处理「合成出新的大梗把邻居挤穿墙」。
  再加一个低速阻尼（`|v| < 22` 时按 0.78 衰减）当作 sleeping，否则密堆会永远抖。
  速度上限 2600，保证不会穿模。
- **合成判定**：`圆心距 < r1 + r2 + 0.6` 且同等级即合成，同一步内一个梗只能参与一次合成。
- **相机/适配**：世界坐标是固定的 350×380（含顶部投放入口共 454 高），按视口算出
  `view / originX / originY` 做整体缩放居中，物理与分辨率无关；手机竖屏、宽屏、矮屏都能完整显示罐子。
- **性能**：背景与罐子（含阴影、裁剪、渐变这些贵操作）烘到离屏画布，只在 resize 时重建；
  梗的径向渐变按「颜色+半径」缓存。这两项把平均帧耗时从 11.2ms 压到 5.2ms（Node 软件光栅下）。
- **可复现**：`?seed=7` 固定随机种子，出货序列完全可重放，方便测试与截图。
- **无依赖降级**：没有 `AudioContext` / `localStorage` 也能正常跑。

## 调试钩子

`window.MergeMeme` 暴露：`state / score / best / chain / bodies / unlocked / danger / cinematic /
layout / curTier / nextTier`，以及 `start() / restart() / drop() / swap() / setAim(x) /

`spawn()` 可以直接放一个指定等级的梗，`drawTier()` 用来单独检查某个梗的画法。

## 已验证

`work/qa/harness-merge.mjs`（假时钟 + Skia canvas + DOM 垫片）直接跑真实 `game.js`：**70 项断言全过**，
12431 帧无异常。覆盖：

- 物理稳定性：无 NaN、无穿墙穿地（`worstOut=0.00`）、速度有上限、堆放会静止、长局不崩；
- 合成与计分公式逐级对账、连击 ×1.5 加成、0.9 秒后连击自然过期；
- 两个飞天奶龙 → 湮灭 → 冲击波清屏 → 虚空坍缩消失的完整链路；
- 乱丢 52 局内必然灌满触发结束（实测 78 次乱丢死亡、峰值危险度 1.50），结束页与记录持久化；
- 4 种视口（390×780 / 1920×1080 / 820×460 / 1280×800）下罐子完整落在屏幕内；
- 交换、重开、图鉴点亮与持久化、音效开关。

美术另外用 `work/qa/gallery.mjs` 把 10 个梗一次性渲染出来逐个检查（这一步抓出了「卡皮巴拉画成了猪」
和「飞天奶龙的翅膀在浅色背景上隐形」两个问题）。

cd work/qa
