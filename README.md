# 尸潮幸存者 Zombie Tide Survivors

顶视角丧尸射击 + 幸存者类波次肉鸽。**纯前端、零依赖、零构建**：双击 `index.html` 即玩，离线可用。

## 快速开始

1. 双击 `index.html`（推荐 Chrome / Edge）。
2. 主菜单 → 开始新游戏 → 选择地图与难度 → 进入战场。
3. 每波结束自动存档；中途关闭浏览器后，主菜单会出现「继续游戏」。

> 如果浏览器禁用了本地存储（隐私模式），游戏仍可玩，但无法保存进度，界面会提示。
> 想让存档更稳妥，也可以用任意静态服务器打开本目录，例如：`python -m http.server 8080`。

## 手机上玩（移动端）

**把游戏送到手机上，三种方式：**

1. **局域网（推荐）**：电脑上双击 `serve.cmd` → 窗口会打印一个手机可访问的地址（形如 `http://192.168.x.x:8080/`）→ 手机连同一个 Wi-Fi，打开该地址即可。
2. **直接拷贝**：把整个 `zombie-tide-survivors` 文件夹拷进手机（数据线 / 微信文件传输 / 云盘），用手机浏览器打开 `index.html`（Android Chrome、iOS Safari 均可）。
3. **静态托管**：纯静态、零依赖，丢到 GitHub Pages / Vercel / 任意静态空间即可分享链接。

**触屏操作（已针对手机重做）：**

| 操作 | 说明 |
|------|------|
| 左半屏任意位置按下并拖动 | 移动（**摇杆在你手指按下的位置出现**，不需要对准固定圆圈） |
| 右半屏任意位置按下并拖动 | 瞄准 + 自动射击（轻点一下 = 朝当前方向持续射击） |
| 右下按钮 | 换弹 / 换枪 / 医疗 / 手雷 / 闪避（均为大号触控按钮） |
| 右上按钮 | ❚❚ 暂停 · ⛶ 全屏（全屏时会自动尝试锁定横屏） |

**体验建议与细节：**

- **建议横屏 + 全屏**：竖屏也能玩（HUD 会自动收紧并溢出提示），但横屏视野更宽。
- **画质模式**：设置 → 画质模式（自动 / 标准 / 省电）。触屏设备默认"自动省电"：渲染倍率降到 1.3×、粒子上限降到 320，帧率更稳。
- **安全区适配**：刘海屏 / 全面屏的边缘会自动留白，HUD 与按钮不会被挡住。
- 切到后台会自动暂停并保存进度；iOS Safari 不支持横屏锁定，全屏后手动横过来即可。
- 存档按浏览器隔离：电脑与手机各自一份进度。

## 玩法速览

- **键鼠**：WASD 移动，鼠标瞄准，左键射击，R 换弹，空格闪避，G 手雷，H 医疗包，Q 换枪，**F 刷新三选一**，ESC 暂停。
- **触屏**：左半屏摇杆移动，右半屏摇杆瞄准并自动射击，右下按钮释放技能。
- 开局先在选图页挑一张**契约**（难度与收益的取舍），再决定难度档位。
- 击杀积累经验 → 升级三选一（武器 / 生存 / 战术），第 5、10 波是精英波，第 15 波是 Boss 战。
- 局外"血清"用于永久强化，共 11 项；通关地图可解锁新地图、噩梦难度与无尽模式。

## 深度玩法（v1.1 新增）

| 系统 | 说明 |
|------|------|
| **契约（风险收益）** | 无契约 / 血肉（生命 -30%，血清 +35%）/ 狂潮（敌人 +35%，经验 +25%）/ 暗影（黑暗视野，敌人加速，血清 +30%） |
| **武器进化** | 武器满 5 级 + 指定强化达标 → 自动进化：圣裁者（手枪）· 龙息霰弹 · 霜冻风暴（冲锋）· 反器材步枪 · 地狱火（火焰）· 天罚（轨道枪） |
| **可破坏物** | 油桶打爆会造成**连锁爆炸**（可用来清场，但自伤也有代价）；补给木箱打碎掉弹药/医疗/手雷/血清 |
| **连杀系统** | 3.5 秒内连续击杀累积倍率（最高 +60% 经验与血清），每 5 连奖励血清；**受击即中断** |
| **精英词条** | 精英丧尸随机携带 1-2 条：狂暴（加速加伤）/ 护盾（减伤 30%）/ 再生 / 剧毒（死后留毒池）；第 7 波起每波都有精英 |
| **刷新三选一** | 每局 1 次起（永久强化「战术预案」再加 2 次），F 键或界面按钮刷新当前三选一 |
| **空投补给** | 第 4 / 8 / 12 波清完后落点，拾取可**免费三选一**（小地图金点标记） |
| **暴君（第三 Boss）** | 地铁与军事基地的最终 Boss：光束扫射（离开光轴！）+ 冲撞连击 + 地刺环爆 |
| **压迫感调优** | 每波丧尸更多、后期整体加速；噩梦难度刷怪 +35%、生命 +70%，精英必带 2 词条 |

## 项目结构

```
zombie-tide-survivors/
├─ index.html          页面骨架与 DOM HUD
├─ css/style.css       主题、HUD、菜单、触屏
├─ js/util.js          数学、随机、空间哈希（可复现种子）
├─ js/data.js          单一事实来源：武器 / 敌人 / 地图 / 升级 / 永久强化 / 成就
├─ js/save.js          localStorage 持久化：档案 + 进行中的一局 + 导出/导入
├─ js/audio.js         WebAudio 实时合成音效与氛围（零音频文件）
├─ js/sim.js           模拟层：AI、流场寻路、碰撞、波次、掉落、升级、存档快照（不依赖 DOM）
├─ js/render.js        渲染层：程序化画面、光照遮罩、小地图
├─ js/ui.js            界面层：HUD、菜单、商店、结算、设置
├─ js/main.js          主循环、输入映射、事件分发、调试钩子
└─ assets/README.md    美术资源接入规范（交给美术 AI 的接口文档）
```

设计原则：**模拟与渲染分离**。`js/sim.js` 不依赖 DOM，可直接在 Node 中做无头测试；渲染层只读取世界状态，不写回。

## 开发者：测试与调试

- 无头冒烟测试（地形 / AI / 波次 / 升级 / Boss / 存档快照）：仓库根目录执行
  `node work/simtest.mjs`（需在项目根运行，测试脚本位于 `work/`）。
- 浏览器调试参数：
  - `?play=1&map=hospital&diff=veteran&wave=7&seed=42&god=1&mute=1` 直接进入指定波次
  - `?debug=1` 预留；F3 切换帧率/实体数浮层
  - 控制台可用 `ZTS.dev.hud()`、`ZTS.dev.setWave(n)`、`ZTS.dev.xp(100)`、`ZTS.dev.god(true)`、`ZTS.dev.win()`、`ZTS.dev.lose()`
- 存档数据结构：`localStorage["zts.save.v1"]`，含 `profile`（血清/强化/解锁/统计/成就/设置/最近 20 局战绩）与 `run`（进行中的一局快照）。

## 美术与音效（已实装）

- **16-bit 像素美术全部程序化实现**：统一调色板、1px 深色描边、两帧步态、方块地块、灯光光池、暗角与扫描线；主菜单是程序化的血月城市主视觉。核心文件：`js/art.js`（调色板 + 15 组精灵 + 主菜单主视觉）、`js/render.js`（地形预处理 + 精灵渲染 + 光影）。
- **镜头**：桌面 1.6×、窄屏/手机 1.3×（更近的"星露谷式"取景），Boss 用 2× 像素尺寸；全部精灵按 2 世界单位/美术像素对齐。
- **验收预览**：`work/preview/render-preview.mjs` 用 Node + `@napi-rs/canvas` 离线渲染真实帧（主菜单 + 5 图 + Boss），`work/preview/sprite-sheet.mjs` 输出精灵试衣间；成品图在 `outputs/previews/`。
- **字体**：数字/拉丁文使用 Press Start 2P（SIL OFL 1.1，12KB，`assets/fonts/`），中文自动回退系统字体。
- **音效**：全部 WebAudio 实时合成，无音频文件；替换素材的命名与接入方式见 `assets/README.md`。
- **想换成 AI/外包素材**：按 `assets/README.md` 产出后替换 `js/art.js` 的 `A.SPR` 条目或 `render.js` 的绘制调用即可，游戏逻辑无需改动。

## 已知限制

- 续玩恢复策略：从"当前波次开头"重建（同种子、同构筑），不保存场上瞬时位置，以避免错位存档。
- 极低端设备（核显 + 300 以上同屏敌人）可能掉帧；可在设置中关闭伤害数字与震动缓解。
